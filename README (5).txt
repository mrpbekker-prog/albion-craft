КАК ВЫЛОЖИТЬ НА GITHUB PAGES (С ТЕЛЕФОНА)

1. Все файлы из этого архива загружаются В КОРЕНЬ репозитория БЕЗ ПАПОК:
   index.html, manifest.json, sw.js, icon-192x192.png, icon-512x512.png
   Папок нет — все пять файлов лежат рядом на одном уровне.

2. GitHub → репозиторий → Add file → Upload files → выберите сразу все 5 файлов.

3. Settings → Pages → Branch: main, папка / (root) → Save.

4. Через 1–3 минуты сайт будет по адресу:
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/

5. Установка как приложение:
   Android/Chrome: меню «⋮» → «Добавить на главный экран».
   iPhone/Safari: «Поделиться» → «На экран "Домой"».
   ПК: значок установки в адресной строке.

ВАЖНО: если поменяете код калькулятора — замените v1 на v2 в файле sw.js,
иначе телефон продолжит показывать старую версию из кэша.
